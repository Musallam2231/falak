# فلك ✦ — موقع ترفيهي بدون سيرفر وبدون API

صفحة ثابتة: يوزر ← درجة عشوائية من 10 + رسالة تحفيزية + بطاقة مشاركة. لا تحليل ولا سحب بيانات، وما يتخزن شي. مكتوب في الموقع أنه للتسلية.

## النشر (5 دقايق، مجاني)
1. GitHub: مستودع جديد باسم falak، ارفع الملفات (index.html وprivacy.html وads.txt).
2. Vercel: Add New ← Project ← Import falak ← Framework: Other ← Deploy. ما تحتاج مفاتيح.
3. جرّب الرابط من جوالك.

## تعديل الرسائل
في index.html ابحث عن TITLES وNOTES، وزد أو غيّر الألقاب والجمل القصيرة.

## الإعلانات (Google AdSense)
1. احصل على دومين خاص (مثل falak.app أو .com) وربطه بـ Vercel: Settings ← Domains.
2. سجّل في adsense.google.com بالدومين، وأضف الموقع، وانتظر الموافقة (أيام إلى أسابيع).
3. بعد القبول: أنشئ 5 وحدات إعلان (Display ads) واحصل على رقم الناشر ca-pub-... وأرقام الوحدات.
4. في index.html عدّل السطر:
   const ADS = { client: 'ca-pub-XXXX', slots: { a: '111', b: '222', c: '333', d: '444', e: '555' } };
5. في ads.txt ضع السطر الرسمي: google.com, pub-XXXX, DIRECT, f08c47fec0942fa0
6. ارفع التعديلات. الأماكن الخمسة: تحت خانة اليوزر، تحت النتيجة (بعيد عن الأزرار)، داخل قسم التعريف، بعد الأسئلة، وقبل الفوتر. وحدة تتركها فاضية تنحذف.

## ملاحظات
- AdSense قد يرفض الموقع إذا حسّه قليل المحتوى. زد صفحات مفيدة (مقالات قصيرة عن نصايح تيك توك) لو انرفض.
- لا تضغط على إعلاناتك ولا تطلب من الناس يضغطون، هذا يسبب إيقاف الحساب.
- لو جمهورك من أوروبا تحتاج شريط موافقة كوكيز (CMP).
- الدخل يعتمد كلياً على الزيارات. مشاركة البطاقة هي اللي تجيب ناس.
